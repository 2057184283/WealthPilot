# 验收与测试

记录日期：2026-09-10。运行环境：Windows，Node.js v24.19.0。

## 已完成的自动验证

- `node scripts/check.mjs`：13 个 JavaScript 模块语法检查及所需静态资产完整性通过。
- `node --test`：29 项测试通过，0 失败。
- 500 组确定性组合样本验证非负、归一、费用和资金守恒。
- API 覆盖读取、修改、预览、模拟执行、重复请求、旧版本冲突、审计、认证、退出、来源校验与非法输入。
- 研究覆盖三种方案的共同约束、最小方差基准、风险贡献、现金底线、策略切换与实际模拟金额一致性。
- AI 覆盖主题选择、上下文最小化、计算依据、超范围问题、服务失败降级；外部提供方使用可控 mock。
- 研究视图的输出字符串检查包含交互入口与恶意文本转义；不等于浏览器交互测试。

## 用户可执行的完整验收

1. 在浏览器打开首页，确认演示数据标记与八个工作页面。
2. 保存风险问卷，确认等级、目标比例和体检结果随输入变化。
3. 进入策略研究，调整费率比较三种方案；选中另一方案后，确认持仓未变化但模拟目标已更新。
4. 到智能配置预览费用，确认后检查资产总额减少的金额等于模拟费用。
5. 到操作记录核对策略变更与交易明细。
6. 修改目标金额、期限与月投入，检查默认 600000 元目标可以正常保存，逐年曲线和数据表一致。
7. 询问“为什么现金目标比例这么高”，确认进入配置解释，并能展开计算依据。
8. 导出 JSON，确认包含自己的最新状态、不含服务器密钥。
9. 停止并重启服务，确认数据保留。
