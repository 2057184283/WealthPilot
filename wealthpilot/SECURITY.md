# 安全说明

本项目处理个人财务研究数据，请仅用于个人可信设备或受访问控制的单用户服务。

## 已有措施

- 默认回环监听；非回环启动要求长口令和明确 PUBLIC_ORIGIN。
- HttpOnly / SameSite Cookie、可选 Secure、8 小时会话。
- 修改请求 Origin 校验、Host 校验、请求大小与频率限制。
- 服务端数值校验、固定静态文件白名单、CSP、用户与模型文本转义。
- SQLite 事务、版本冲突检测、幂等执行。
- 模型密钥仅在服务端，外部发送需逐次同意，模型不具备交易或数据库写权限。

## 已知限制

没有多用户隔离、MFA、共享会话/限流、数据库加密、自动备份、防篡改审计或安全渗透测试。SQLite 与 JSON 导出包含财务信息；有机器或数据库权限的人可读取和修改。

提示词指令不能保证模型忠实、安全或准确。模型没有真实交易能力，但可能给出错误解释。用户输入问题中的敏感信息仍可能发送到配置的外部服务。提供方 URL 由可信部署者设置；尚未提供面向不可信用户的提供方管理和网络出口控制。

没有账户恢复机制。丢失口令时由部署者安全地更新 ACCESS_TOKEN 并重启。不要向不互信用户共享同一个实例。

## 报告问题

若在你自己的 GitHub 仓库中启用私密漏洞报告，请通过该渠道联系维护者；公开 issue 中不要包含密钥、真实财务数据、会话 cookie 或可被利用的敏感细节。发现暴露的密钥应在原服务中撤销并更换，删除 Git 文件不能撤销泄漏。
