# 贡献指南

使用 Node.js 24+。核心代码无第三方运行依赖，修改后执行：

```bash
node scripts/check.mjs
node --test
```

- 金融计算放入纯函数模块，避免在页面中复制公式。
- 修改规则须更新策略版本、算法文档、边界测试和用户可见依据。
- 数据写入走 storage 事务；保持版本检查和幂等语义。
- 新行情源须保留来源、时间与数据状态，禁止把模拟数据称为真实回测。
- AI 不得直接控制交易；外部上下文发送遵循最小必要原则。
- 新增依赖前说明目的、许可证、部署影响与可替代方案。
- 不提交 `.env`、数据库、财务导出或第三方密钥。

PR 描述请写清触发问题、实际变化和验证结果。财务或安全变更需要有针对性的测试；文案与低风险样式调整不需要机械增加测试。
