# 知衡 WealthPilot

知衡 WealthPilot 是一个面向个人投资者的 AI 理财研究与模拟投资工作台。

它帮助用户把风险承受能力、资产配置、投资目标和模拟调仓放在同一个流程中理解和管理。系统会解释每一步计算依据，展示不同市场情景下的可能影响，并保留操作记录，方便用户复盘自己的理财计划。

> 本项目仅用于理财教育、研究和模拟投资，不构成投资建议，不连接真实交易账户，也不承诺任何收益。

## 为什么做这个项目？

很多理财工具只回答“应该买什么”，却没有解释：

- 这个配置是否符合自己的投资期限？
- 市场下跌时，组合可能承受多大压力？
- 距离自己的资金目标还有多远？
- 调整资产时，费用和现金储备会受到什么影响？
- AI 的结论究竟依据了哪些数据和规则？

知衡希望把这些问题放进同一个可检查的决策流程中，让用户先了解自己的约束，再比较方案，最后进行模拟操作。

## 核心功能

### 1. 风险测评

系统综合考虑以下因素：

- 投资期限
- 对资产下跌的承受能力
- 投资经验
- 收入稳定性
- 应急资金储备
- 负债利率
- 每月必要支出

测评结果采用透明的规则计算。系统会同时评估用户的风险意愿和财务承受能力，并以较低的一项作为风险等级上限。

### 2. 智能资产配置

根据风险画像，系统生成权益、债券、黄金和现金四类资产的参考比例，并根据必要支出调整现金储备比例。

用户可以看到：

- 当前资产比例
- 参考目标比例
- 各类资产的配置偏离
- 形成该配置的具体原因
- 是否需要进一步检查现金和负债情况

### 3. 策略研究

项目提供三种可比较的配置方案：

- 风险规则配置：依据风险等级和现金需求生成基准方案。
- 约束逆波动配置：波动越高的资产，参考权重越低，同时受到权益和黄金上限约束。
- 网格最小方差配置：在给定约束内，通过有限网格搜索假设波动较低的方案。

三种方案使用相同的参数、现金底线和费用假设，用户可以比较配置比例、假设波动、压力情景、成交额和模拟费用。

### 4. 压力测试

系统提供四种教学情景：

- 权益资产急跌
- 利率冲击
- 通胀压力
- 多类资产同步下跌

压力测试展示的是固定假设下的一次静态结果，不是历史回测、最大回撤或未来损失上限。

### 5. 目标规划

用户可以设置目标金额、目标年限、每月投入、年化收益假设和通胀假设，系统计算：

- 目标期限结束时的资产测算
- 当前投入下的目标缺口
- 达到目标所需的月投入
- 扣除通胀后的参考购买力
- 逐年资产变化和累计投入

系统会明确标注这些结果属于固定假设下的复利测算，不代表未来收益。

### 6. AI 理财助手

AI 助手可以解释：

- 当前风险等级
- 资产配置偏离
- 压力测试结果
- 目标资金缺口
- 不同策略之间的差异

项目默认使用本地规则解读，不需要配置模型密钥。接入兼容 Chat Completions 协议的模型服务后，用户可以在明确同意的情况下使用外部 AI 解读。

AI 只负责解释已经计算出的结果，不能修改资产数据、执行调仓或发出真实交易指令。每次回答都会保留计算依据、策略版本和参考资料。

### 7. 模拟调仓和操作记录

在执行模拟调仓前，系统会展示：

- 调整前金额
- 调整后金额
- 每类资产的变动金额
- 预计交易费用
- 调整后的组合总额

确认后才会写入模拟账本。系统使用 SQLite 事务、版本检查和幂等键，避免重复提交或用旧页面覆盖新数据。

## 技术特点

- Node.js 24 原生服务端
- 原生 HTML、CSS 和 JavaScript 前端
- SQLite 本地持久化
- 无第三方运行时依赖
- 服务端输入校验
- 登录口令和 HttpOnly 会话
- Origin、Host、CSP 和请求频率限制
- 模拟调仓事务与审计记录
- 可选 Docker Compose 部署
- GitHub Actions 自动测试
- 中文界面与中文文档

## 项目结构

```text
wealthpilot/
├── server.mjs              # HTTP 服务、API、认证和静态文件
├── src/
│   ├── domain.mjs          # 风险、配置、目标和压力测试
│   ├── strategies.mjs      # 配置策略与比较逻辑
│   ├── evidence.mjs        # AI 问题分类与计算依据
│   ├── advisor.mjs         # 本地规则和外部 AI 适配器
│   └── storage.mjs         # SQLite、版本和审计记录
├── public/                 # 前端页面和样式
├── tests/                  # 单元测试和接口测试
├── docs/                   # 产品、算法、部署和安全文档
├── Dockerfile
├── compose.yaml
└── .github/workflows/ci.yml
```

## 如何运行

需要 Node.js 24 或更高版本。

```bash
node --env-file-if-exists=.env server.mjs
```

然后打开：

```text
http://127.0.0.1:3000
```

项目不需要执行 `npm install`。首次启动会自动创建本地 SQLite 数据库，并使用明确标记的演示资产。

## 运行测试

```bash
node scripts/check.mjs
node --test
```

测试覆盖风险规则、资产配置、策略比较、目标测算、压力测试、费用守恒、版本冲突、幂等执行、认证、跨站请求保护和 AI 降级逻辑。

## 数据和隐私

项目默认只监听本机地址。用户资产、问卷和操作记录保存在本地 SQLite 数据库中，不会自动上传到第三方服务。

如果配置外部 AI 服务，系统只在用户明确同意后发送问题和必要的比例、标签及计算结果，不发送服务端密钥。请不要在问题中填写身份证号、银行卡号、账户密码或其他敏感信息。

## 项目边界

当前版本适合作为个人研究工具、理财教育项目、开源作品集和智能投顾原型。

尚未实现：

- 实时行情接入
- 历史回测
- 多用户账户隔离
- 税务计算
- 券商账户连接
- 真实订单执行
- 持牌投顾合规流程

因此，本项目不能直接作为面向公众的商业投顾系统使用。正式部署前，还需要补充身份体系、数据权限、行情质量、备份恢复、合规审查和真实交易隔离等能力。
